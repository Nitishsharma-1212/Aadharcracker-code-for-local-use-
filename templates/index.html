How to Use the Decryptor

Step 1: Select and upload your locked Aadhaar PDF file.

Step 2: Fill in the Name Hint and Year Range (Crucial!).

⚡ Pro Tip for 1-Second Results:

If you know the person's name, type the first 4 letters in the Name Hint box (e.g., if the name is Rahul, type RAHU). With a Name Hint, the password will be unlocked in just a few seconds!

⏳ Without a Name Hint:

If you leave the Name Hint empty, the engine will try every possible name combination. This process can take a significantly longer time (several minutes or more).
